# SistemaGanadero

Sistema de gestión ganadera orientado al control del proceso de **compra, engorde y comercialización de ganado bovino**.

El sistema permite centralizar la información de los animales y lotes, controlar las compras e inversiones y realizar el seguimiento del desarrollo de los animales durante el ciclo de engorde.

## Funcionalidades

- Registro y gestión individual de animales.
- Creación y administración de lotes de engorde.
- Registro de compras y proveedores.
- Control del peso inicial y evolución del ganado.
- Seguimiento de la inversión por animal y por lote.
- Dashboard con indicadores generales del negocio.
- Base de datos centralizada para mantener la trazabilidad de la información.

## Objetivo

Proporcionar una herramienta que permita conocer el estado productivo y económico del ganado en cada etapa del ciclo, facilitando el análisis de la inversión y la toma de decisiones sobre el momento de venta.

El sistema se desarrolla inicialmente con procesos manuales y está diseñado para evolucionar progresivamente hacia la automatización.

## Automatización futura

La arquitectura permitirá incorporar posteriormente tecnologías como:

- Escaneo automático de aretes.
- Integración con básculas electrónicas.
- Pesaje inalámbrico.
- RFID.
- Dispositivos IoT.
- Automatización de captura de datos.
- Indicadores avanzados de rentabilidad.

## Tecnología

- **Frontend:** React + Vite
- **Backend:** Python + FastAPI
- **Base de datos:** PostgreSQL
- **Infraestructura:** Docker
